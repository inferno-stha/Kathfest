🎓 Smart Student Attendance System

Version 2.0 (Hackathon Ready)

An automated attendance system that uses face recognition to identify students and record their attendance, removing the need for manual roll calls. Built for a hackathon to demonstrate a full-stack web application workflow.

v2 features: automatic attendance with confidence scoring, ROI-restricted face detection, duplicate face guard, face search, individual graphical reports, dashboard charts, and input validation.
